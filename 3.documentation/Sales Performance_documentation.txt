# Excel Sales Performance Dashboard – Project Documentation

## 1. Project Overview

The **Excel Sales Performance Dashboard** is an end-to-end data analysis project developed using Microsoft Excel.

The project uses sales data to analyze the performance of Sales Executives across different regions. Excel formulas, Pivot Tables, Pivot Charts, and interactive dashboard elements are used to convert raw sales data into meaningful business insights.

The project contains **141 sales records** across **8 regions/cities** and tracks sales performance over five days.

---

## 2. Project Objectives

The main objectives of this project are:

* Analyze Sales Executive performance.
* Calculate total sales for each employee.
* Compare actual sales against the assigned target.
* Calculate Target Hit Percentage.
* Identify high and low-performing employees.
* Analyze sales across different regions.
* Create interactive visual dashboards.
* Present business information in an easy-to-understand format.

---

## 4. Data Preparation

The raw dataset is stored in the **RAW DATA** worksheet.

Calculated columns are created using Excel formulas.

### Total Sales

Total sales are calculated by adding sales from Day 1 to Day 5:

```excel
=SUM(D2:H2)
```

### Target Hit Percentage

The percentage of the target achieved is calculated using:

```excel
=I2/J2
```

The result is formatted as a percentage.

### Away From Target Percentage

The remaining percentage required to reach the target is calculated using:

```excel
=100%-K2
```

These calculations make the raw dataset ready for Pivot Table analysis.

---

## 5. Pivot Table Analysis

Pivot Tables are used to summarize the raw sales data.

The project contains different views of sales performance, including:

### Sales Executive vs Total Sales

This analysis shows the total sales generated by individual Sales Executives.

It helps identify:

* Top-performing employees
* Low-performing employees
* Differences in sales performance

### Sales Executive vs Target Hit %

This analysis shows how much of the assigned target each Sales Executive achieved.

For example:

* 100% = Target completely achieved
* Above 100% = Target exceeded
* Below 100% = Target not completely achieved

---

## 6. Dashboard Design

The dashboard provides a visual representation of the sales analysis.

The dashboard contains multiple views, including:

### Dashboard 1 – Sales Performance

Displays Sales Executive-wise total sales using a horizontal bar chart.

This makes it easier to compare employees based on their total sales.

### Dashboard 2 – Sales Summary

Provides another summarized view of Sales Executive performance using Pivot Table data.

### Dashboard 3 – Target Achievement

Displays Target Hit Percentage using a visual chart.

This allows users to quickly understand how effectively employees are performing against their targets.

### Dashboard 4 – Target Performance Trend

Uses a line chart to visualize Target Hit Percentage across selected Sales Executives.
