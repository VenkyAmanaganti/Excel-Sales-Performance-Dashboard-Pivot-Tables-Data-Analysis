# Excel Pivot Table – End-to-End Sales Dashboard

## 📊 Project Overview

This project is an **end-to-end Excel Sales Dashboard** created using Pivot Tables, Pivot Charts, and interactive dashboard elements.

The goal is to analyze sales performance, employee-wise sales, and target achievement and present the results in an easy-to-understand visual format.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Dashboard
* Data Analysis
* Slicers / Interactive Controls
* Conditional Formatting

## 📌 Key Features

* Employee-wise total sales analysis
* Target achievement percentage analysis
* Sales performance comparison
* Interactive city-based filtering
* Multiple Pivot Tables
* Bar chart for sales performance
* Pie chart for target distribution
* Line chart for target achievement
* Interactive dashboard with multiple views

## 📈 Dashboard Insights

The dashboard provides different views of the sales data, including:

* Total sales by Sales Executive
* Target Hit % by Sales Executive
* Comparison of individual performance
* City-wise filtering
* Visual representation of target achievement

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.xlsm` Excel file using Microsoft Excel.
3. Enable macros/content if prompted.
4. Go to the **Dashboard** sheet.
5. Use the city buttons/filters to interact with the dashboard.
6. Explore the Pivot Tables and charts to analyze sales performance.
